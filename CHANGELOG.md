## Release process

1. Confirm all release-gate items in `ROADMAP.md`.
2. Update this file with user-visible changes and migration notes.
3. Update the version and compatibility matrix in the release artifacts.
4. Create an annotated Git tag such as `v0.1.0` only after tests and deployment verification.
5. Publish known limitations and upgrade/rollback guidance.
